# Intro
This is a very basic Instagram scraper that uses the `selenium` library, combined the `chromium webdriver` to scrape Instagram profiles for Followers and Following.
It logs into a given account and stores all the data locally in simple text files for further processing and easy access by a user.
Plan is to further develop this into a more advanced scraper that can scrape more data and store it in a more structured way + provide a GUI for easier use.

## Easily scrape Instagram
this scraper is very simple to read and understand, and can be easily modified to scrape more data from Instagram or made a bot to automate certain tasks.


# Requirements
- Python 3.6+
- Selenium
- Chromium Webdriver

# Installation
1. Clone the repository
2. Install the required libraries
3. Download the Chromium Webdriver
4. Run the script

# Usage
1. Run the script
2. Enter your Instagram credentials
3. Select the action you want to perform
4. Enter the username of the profile you want to scrape
5. Wait for the script to finish
6. Check the output folder for the results
